# Haptics360

**Feel the track.**

Haptics360 is a Windows sim-racing haptics engine in development — it drives a
ButtKicker shaker and a Simagic P-HPR brake pedal from a single live mix:
engine, road, impacts, ABS and lockup cues, every one tunable while you drive.

**Status: in development.**

This repository hosts the public project page and brand assets only.
The application itself is closed source and is not distributed here.
