02 Outputs

Built for the rig, not the spec sheet

Most haptics tools push everything through one channel. Haptics360 treats your shaker and your brake pedal as separate instruments in the same mix — each with its own gain, its own frequency band, its own mute — then sums them against the same telemetry.

ButtKicker channel

The body channel — low frequencies, sustained cues.

  • Native LFE passthrough — the game's own low-frequency effects, levelled and limited.
  • Synthesised effects — engine, gears, kerbs and impacts rendered as motor drive.
  • Grouped mix — engine / road / impacts / wheels sub-mixes under one master.

P-HPR pedal channel

The precision channel — high-frequency cues at the foot.

  • Direct motor control — brake-pedal actuator driven cue by cue, 10–100 Hz.
  • Pedal-specific effects — ABS pulses, lockup buzz, kerb rumble, road impacts.
  • Per-cue envelopes — pulse width, duration and trigger thresholds per effect.

04 Live tuning

Change it mid-corner. It just works.

Settings are applied atomically — a change is live in about a quarter of a second, with no restart, no audio glitch, no lost telemetry. The same knobs are exposed to scripts and AI agents over a plain command line, and a 4 Hz monitor streams the live state of both outputs while you drive.

haptics360 — live
# soften the shaker's impact channel
$ haptics360 tune set bk.impacts.gain=-25

# wake up the pedal's kerb cue, split the frequencies
$ haptics360 tune set pedal.road_impacts.gain=+25 pedal.road_impacts.freq_hz=20

# watch both outputs live, 4 Hz
$ haptics360 monitor --watch

click a tune command to hear it on the bench above

  • Atomic applies — every change lands whole, in ~0.25 s, mid-session.
  • Relative or absolute — +25 nudges, =80 sets.
  • Filterable inventory — tune list --filter pedal. shows one branch.
  • Solo audition — isolate any single effect to hear it alone before blending it back in.
  • Agent-friendly — the same CLI answers in JSON for automation and AI tooling.

05 Under the hood

Built like a instrument, not a wrapper

Telemetry is sampled at 360 Hz and played out against the wall clock, so every cue lands where the sim actually is — not where it was a frame ago. A fitted predictor covers the last few milliseconds, and the mix splits into bands so the shaker and the pedal never fight over the same frequencies.

360 Hz telemetry

A dedicated high-rate stream buffers every sample and synchronises playout to the wall clock — sub-frame cue timing, not frame-slaved triggers.

Predictive playout

A fitted predictor carries the signal a few milliseconds forward, so the pedal answers the corner entry — not the telemetry packet that reported it.

Split-band mix

Low band to the shaker, high band to the pedal, crossfaded at the crossover — each device keeps the frequencies it's built for.

Native + synthesized

The game's own LFE and Haptics360's rendered effects run as independent branches under separate masters — blend or mute either.

Replay & reference

Capture a session's telemetry at 360 Hz or replay a recorded one offline — audition effects and fit predictors without turning a wheel.

06 Questions

The honest answers

Which devices does it drive?

Direct-output haptic hardware — the shaker channel suits transducer-style motors like the ButtKicker, and the pedal channel is built for force-feedback brake pedals such as the P-HPR. More device profiles are added as the hardware earns them.

Where does the telemetry come from?

Live telemetry shared into Haptics360's own memory interface, plus offline replay of recorded sessions — the same engine drives both, so you can tune against a lap you already drove.

Does it work with my sim?

If your sim publishes telemetry, Haptics360 can feel it. The effect catalog covers road, powertrain, contact and aero cues across racing, flight and motion platforms.

Can I script it?

Yes — the live-tuning CLI takes plain commands and returns JSON, so scripts, dashboards and AI tooling can read and write the same knobs you do.

Is it free?

Pricing isn't decided yet — this page tracks the product as it develops. The coffee link keeps the project alive meanwhile.
